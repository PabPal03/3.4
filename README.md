# 3.4 Performance Assessment

Angular and React apps with the same requirements:

- Text input labeled **Message to Display**
- Button labeled **Display Message**
- Heading that starts as **Hello World** and updates when the button is clicked

## Angular

```bash
cd angular-app
npm install
ng serve
```

Open http://localhost:4200

## React

```bash
cd react-app
npm install
npm start
```

Open http://localhost:3000
